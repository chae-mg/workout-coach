# ADR-002: GitHub Pages를 기본 웹 호스팅으로 사용

- 상태: 승인
- 결정일: 2026-09-23

브라우저 앱의 기본 배포 대상으로 GitHub Pages를 사용한다. 앱은 정적 파일만 필요하므로 GitHub Actions가 `apps/web/`만 Pages에 게시한다. 개발·검증은 기존 로컬 앱을 계속 사용하고 GAS 번들은 선택 가능한 이전 호환 경로로 유지한다.

앱에는 로그인이나 서버 저장 기능이 없다. 설정과 진행 상태는 브라우저 `localStorage`에 저장되며 GAS 주소와 Pages 주소 사이에 자동 공유되지 않는다. 소스 저장소와 Pages가 공개된다는 점을 배포 기준으로 삼는다.
