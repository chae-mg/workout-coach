# Next

GitHub Pages 배포 후속 확인:

1. 저장소 Settings → Pages에서 배포 원본을 `GitHub Actions`로 설정한다.
2. `main`에 변경 사항을 푸시하고 `Deploy GitHub Pages` 작업이 성공하는지 확인한다.
3. [`https://chae-mg.github.io/workout-coach/`](https://chae-mg.github.io/workout-coach/)에서 앱과 정적 자원이 열리는지 확인한다.
4. 새 주소는 별도 브라우저 저장소를 사용하므로 필요한 설정을 다시 지정한다.

사용자가 보류한 Android 실기기 검수는 Pages 주소가 열린 뒤 원할 때 재개할 수 있다. 진동은 제품 범위에서 제외한다.
