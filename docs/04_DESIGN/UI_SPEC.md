# UI_SPEC — Workout Coach

## 1. UI 원칙

### Mobile-first

주 사용 환경이 모바일이므로 모든 핵심 기능은 스마트폰 Portrait 기준으로 설계한다.

### Workout 중 최소 조작

운동 중에는 필요한 기능만 노출한다.

```text
현재 운동
목표
세트
Tempo
완료
Skip
```

설정, 기록 등의 Navigation은 숨긴다.

### Desktop

모바일 Layout을 중앙 정렬한다.

권장:

```css
.app-shell {
  width: 100%;
  max-width: 560px;
  margin: 0 auto;
}
```

```text
[          세트 완료          ]

건너뛰기                     ···
```

### TIME 운동

횟수 대신 Timer.

TIME은 설정된 세트 수로, TIME_BLOCK은 1구간으로 진행한다. 진입 직후에는 타이머를 대기시키고 `타이머 시작` 버튼으로 시작한다. 진행 중에는 `일시정지`, 멈춘 뒤에는 남은 시간을 유지하고 `타이머 재개`로 이어간다. 다음 시간 운동·세트의 타이머는 직접 시작한다.

```text
00:42
```

필요 시:

```text
[ Pause ]
```

# 6. Rest

```text
             휴식

             01:18

          ● ● ● ● ●

다음

팔굽혀펴기 · SET 3 / 3
8~15회 · 가슴·삼두

[ -15초 ]          [ +15초 ]

[       휴식 건너뛰기       ]
```

3초 이하:

```text
00:03
00:02
00:01
```

Sound / Vibration 설정 반영.

휴식이 자연 만료되고 종료음이 켜져 있으면 `휴식이 끝났어요` 화면에서 다음 운동·세트와 `휴식 알람 끄기` 버튼을 표시한다. 종료음은 확인할 때까지 반복하고 다음 세트 완료·시간 타이머·Tempo는 대기한다. 알람을 끄면 다음 대상의 Player를 표시하며 수행 합계는 바뀌지 않는다.

안내음 모두 끄기와 운동 종료도 제공한다. 오디오가 중단되면 활성화 버튼을 표시한다. 새로고침 후 이어하기로 미확인 알람을 복구하며, 알람을 이미 끈 세션에서는 다시 울리지 않는다. 종료음 OFF·음소거·휴식 건너뛰기에는 확인 화면 없이 진행한다.

# 8. 설정

Player의 안내음 버튼은 세션의 소리 전체를 켜고 끄며 상태를 표시한다. 오디오가 중단되면 안내음 활성화 버튼을 표시하고, 미지원·활성화 실패는 알림으로 안내한다. 화면 안내와 완료 조작은 계속 사용할 수 있다.

Tempo·휴식 종료음·3초 카운트는 각각의 설정을 따른다. 운동별 Tempo OFF는 해당 운동의 Tempo 소리만 끈다. 숨겨진 화면에서는 소리를 내지 않는다. 화면 테마는 다크 모드와 라이트 모드 중 선택하며 브라우저에 저장한다. 화면 꺼짐 방지 미지원이나 실패가 운동 조작을 막지 않도록 한다.

```text
설정

운동

기본 세트 수              운동 기본값 >
기본 휴식                운동 기본값 >
운동 간 휴식                 120초 >

사운드 / 알림

화면 테마                       다크 모드

Tempo Sound                    ON
휴식 종료음                     ON
종료 3초 카운트                 ON
화면

화면 꺼짐 방지                  ON
운동별 설정                      >
```

# 9. 운동별 설정

예:

```text
← 팔굽혀펴기

목표 횟수
[ 8 ]  ~  [ 15 ]

세트
[ 3 ]

휴식
[ 90초 ]

Tempo
[ 2 ] - [ 1 ] - [ 1 ]

Tempo Sound
ON

[ 저장 ]
```

운동별 설정이 없으면 Global / Exercise Default 사용.

기본 세트·휴식의 빈 값은 운동 기본값 상속이다. 직접 지정한 기본값보다 운동별 설정이 우선한다. 운동별 편집에서 저장한 값은 기본 설정을 바꿔도 유지하며 `개별 설정 해제`로 기본 설정을 다시 사용한다.

# 10. Resume Dialog

반복 운동·휴식·진행 중이던 시간 운동·멈춘 타이머를 구분한다. 멈춘 타이머는 남은 시간을 표시하고 이어하기 후에도 대기한다. 진행 중이던 타이머는 저장한 종료 시각을 유지한다. 만료된 시간 운동은 현재 세트·구간 하나만 완료하고 필요한 휴식을 이어한 시각부터 시작한다. 새 운동 시작은 기존 세션과 오늘 조정을 비우며 완료 상태는 완료 화면을 복원한다.

`active_session` 존재 시:

```text
진행 중인 운동이 있습니다.

팔굽혀펴기
SET 2 / 3

[ 이어하기 ]

[ 새 운동 시작 ]
```

# 13. Navigation

일반 화면:

```text
홈
기록
설정
```

MVP에서 기록 기능이 아직 없으면 `기록`은 완료 화면 또는 Placeholder로 연결해도 된다.

Workout 및 Rest 화면에서는 Bottom Navigation을 숨긴다.

홈의 선택 요약은 세로 화면에서 하단 메뉴 위에 고정한다. 높이 500px 이하의 가로 화면에서는 목록과 함께 스크롤해 운동 카드의 이름·터치 영역을 가리지 않도록 한다. 목록 끝에서 오늘 운동 확인 버튼에 접근할 수 있다.
