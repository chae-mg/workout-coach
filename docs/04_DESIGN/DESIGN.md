# Workout Coach 디자인 기준

기준 자료는 레포의 [UI_SPEC.md](./UI_SPEC.md)와 [PRD.md](../01_PRODUCT/PRD.md)다. 외부 앱의 자산이나 서체를 복제하지 않고 기존 모바일 화면 구조를 구현했다.

- 화면은 최대 560px 너비로 가운데 배치한다. 운동 선택은 2열이며 가로 화면에서도 핵심 버튼에 접근할 수 있게 세로 스크롤을 허용한다.
- 높이 500px 이하의 가로 화면에서는 선택 요약을 목록과 함께 스크롤한다. 고정 요약 영역이 운동 카드의 이름과 터치 영역을 가리지 않도록 한다.
- 어두운 배경 `#101b20`, 카드 `#19292f`, 본문 `#f2f5f3`, 보조문 `#afc0c3`를 사용한다. 진행·목표는 민트 `#b8e8da`, 주요 행동은 주황 `#ffbd83`으로 구분한다.
- 한국어는 시스템 서체를 사용하고 제목과 운동명의 어절을 가능한 한 유지한다. 긴 운동명은 카드·대화상자 너비에서 줄바꿈한다.
- 주요 버튼은 최소 48px, 필터·입력·보조 행동은 최소 44px 높이다. 포커스 표시, 선택 상태, 입력 레이블, 오류 안내와 대화상자 포커스 이동을 제공한다.
- 운동·휴식 화면에서는 하단 메뉴를 숨긴다. 시간 숫자는 자릿수 폭이 일정한 숫자 스타일을 사용한다.
- 운동 이미지와 아이콘은 `apps/web/public/`의 직접 만든 SVG다. 운동 이미지는 공통 샘플이며 자세 설명용이 아니라는 문구를 표시한다. 실제 동작 이미지는 이후 운동의 `imageUrl`을 교체한다.
- 이 색상·형태는 이번 앱을 위한 구현 선택이며 별도 브랜드의 공식 규격을 의미하지 않는다.
